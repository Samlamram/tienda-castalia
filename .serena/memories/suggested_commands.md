# Commands (PowerShell, project root)
- Start dev server: `npm run dev`
- Type-check/lint gate: `npm run lint`
- Run tests once: `npm run test`
- Production build: `npm run build`
- Preview build: `npm run preview`
- Fast search on Windows: `rg -n "pattern" src`; list files: `rg --files`.
- Deploy product-image function when relevant: `supabase functions deploy product-image --no-verify-jwt`.
